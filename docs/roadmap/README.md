# Roadmap: implementaciones futuras

Espacio para organizar trabajo *planeado* sobre `vecdiff`: qué falta, por qué,
y en qué orden conviene hacerlo. No documenta lo ya implementado (eso vive en
el `README.md` raíz y en `docs/notebooks/`), sino la deuda de diseño.

## Convención

- Un archivo por línea de trabajo, numerado: `NN_tema.md`.
- Cada archivo empieza con el **objetivo** en una frase, sigue con los
  **límites actuales** (con referencia a archivo:línea) y termina con un
  **TODO** en casillas.
- Cuando un ítem se implementa, se marca `[x]` y se anota el commit o el
  cuaderno que lo verifica. Cuando la línea entera se cierra, el archivo se
  borra y lo que quede útil pasa a los docs normales.
